# 群星 (Stellaris) 世界观参考

> 版本: v4.4.3 / 来源: 百度百科、官方Wiki、社区 | 最后更新: 2026-06-21

## 基础设定
- 时间: 公元2200年，多个文明同时掌握超光速技术迈入星际时代
- 文明类型: 人类、爬行类、真菌类、机械意识、蜂巢思维等
- 政体: 民主共和、帝制独裁、寡头制、企业政府等
- 核心思潮(10种): 和平/军国、平等/威权、唯心/唯物、亲外/排外、格式塔(蜂巢/机械)
- 起源系统: 繁荣一统、虚空居者、破碎之环、克隆大军、末日降临等数十种
- 平行宇宙: "虚境"(The Shroud)是重要的平行维度

## 飞升路径
- **基因飞升**: 改造DNA，创造完美种族。4.0版重制为克隆/纯净/突变三条路线
- **机械飞升(合成进化)**: 意识上传机械体，获得永生。机械纪元DLC重构
- **灵能飞升**: 接触虚境，获得超自然力量。即将到来的虚境幽影DLC将重置
- **纳米飞升**: 机械纪元新增，专精纳米技术
- **天灾飞升(灾飞)**: 化身银河天灾，通过积攒威力度摧毁银河
- **宇宙创生**: 机械文明飞向另一个宇宙
- **巨兽之怒**: 养育生物巨兽吞噬银河(BioGenesis新增)
- **星系热症**: 将星系化为灰烬(炼狱种族包新增)

## 失落帝国 (Fallen Empires)
五种类型: 神秘观察者(亲外)、军事孤立者(排外)、圣地守卫者(唯心)、知识管理者(唯物)、上古看守者(机械)
后期可能"觉醒"(Awakened Empire)，两个对立帝国同时觉醒→"天堂之战"(War in Heaven)
BioGenesis新增: 堕落蜂巢帝国(支离破碎)，三种分裂人格的破碎蜂巢思维

## 终末危机 (End Game Crisis)
### 经典三大危机
- **索林原虫(Prethoryn Scourge)**: 银河外逃亡生物，被"猎手"追捕。虫群战术，护甲极高无护盾，弱能量武器。占领星球产卵。
- **肃正协议(The Contingency)**: 上古AI防御系统，消灭接近"30级奇点"的文明。先释放幽灵信号同化合人，在四个机械星球建立信号中枢。
- **破界者(Unbidden)**: 异次元能量生物，使用物质分解器(部分无视防御)。需摧毁维度锚才能攻击传送门。后续出现金/绿恶魔变种。

### 机械纪元新增
- **合成女王塞塔娜(Cetana)**: 合成人女王，初始不敌对(+50好感)。目标是终结所有意识以终结一切痛苦。好感系统复杂，可外交互动/接受任务/提供资源。核心星系被纳米风暴笼罩。击败奖励遗珍「塞塔娜之心」。

## 特殊势力
- **游牧劫掠者(Marauders)**: 太空游牧民族，后期大可汗统一发动大远征
- **利维坦(太空巨兽)**: 以太龙、噬星者、虚空孳孽、位面之魇等，每局随机四个
- **行商舰队**: 流动贸易商队
- **飞地**: 艺术家、贸易商、策展人

## 巨型建筑
- 戴森球、环世界、物质解压器、科学枢纽
- 哨兵阵列(全银河探测)、巨型艺术设施、星际集会
- 量子弹射器、主宰(移动巨型船坞)
- 机械纪元新增: 电弧熔炉、戴森群(Dyson Swarm)、突触凝练机(烧脑巨构)
- BioGenesis新增: 深空擎天堡(防御型巨构，可在任意星系建造)

## 舰船体系
- 护卫舰→驱逐舰→巡洋舰→战列舰→泰坦(搭载超级武器+旗舰光环)→巨像(可摧毁行星)
- 主宰(移动巨型船坞)、生物舰船(BioGenesis新增): 颚蚁(护卫舰)、织蛛(驱逐舰)、孵后(航母)、刺蜂(战列舰)。主要消耗食物建造和维护，有幼体→成熟体→年长体成长系统

## 外交
- 星海共同体: 银河议会，投票决定法律，可设立监管人→宣布银河帝国
- 联邦: 军事/经济联盟(联邦DLC强化)
- 附庸系统(四海皆臣DLC大改)
- 情报/谍报系统(复仇女神DLC)
